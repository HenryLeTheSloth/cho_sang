# M1 Catalog: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Load skill `react-router` trước khi đụng route; `prisma-client-api` trước khi viết query. **Không** load `prisma-orm-setup`.

**Goal:** Khách xem được toàn bộ catalog trên điện thoại: trang chủ, danh mục, tìm kiếm không dấu, sắp xếp/lọc, "Xem thêm", trang sản phẩm có đủ thông tin tạo niềm tin, trang Giới thiệu và Liên hệ. Ảnh được phục vụ từ `uploads/`.

**Architecture:** Mọi trang render server (loader + Prisma). Lọc, sắp xếp và phân trang nằm hoàn toàn trên URL (`?q ?sort ?instock ?page`) và đều là `<Link>`, nên chạy được khi chưa có JS. Query Prisma được dựng bởi một hàm thuần (`productFindArgs`) có unit test, kèm test tích hợp chạy trên DB đã seed. Ảnh đi qua resource route `/uploads/*` với whitelist tên file.

**Tech Stack:** react-router 8.4.0, Prisma 7.10.0, Tailwind 4.3.3, lucide-react 1.56.0, sharp 0.35.5, vitest 5.0.4. Lighthouse 13.5.0 chạy bằng `npx` (không thêm vào dependency) với `/usr/bin/google-chrome`.

**Spec:** [docs/superpowers/specs/2026-10-14-cho-sang-grocery-design.md](../specs/2026-10-14-cho-sang-grocery-design.md), các mục 3 (MVP Home/Collection/Product/About/Contact), 4, 5 (route map, ngân sách), 6 (dòng M1). Roadmap: [2026-10-14-cho-sang-roadmap.md](2026-10-14-cho-sang-roadmap.md), gồm hợp đồng module và mục "Kết quả M0" (việc chuyển sang M1).

## Global Constraints

- Phiên bản đã ghim ở M0. **M1 không thêm dependency nào.**
- Cấm `@remix-run/*`. Tiền là `Int` VND, hiển thị qua `formatVnd()`, luôn kèm đơn vị bán.
- Tiếng Việt trên mọi chữ hiển thị. Bố cục 375px làm trước. Vùng chạm ≥44px (`min-h-11`). Có trạng thái hover và focus-visible.
- Magenta (`brand`) chỉ dùng cho CTA, giá bán, badge giỏ, logo, focus ring. `fresh` mang **một** nghĩa duy nhất là còn hàng/tươi. `sun` chỉ dùng cho badge khuyến mãi (chữ `ink` trên nền `sun`). Không đặt chữ trắng hay magenta trên nền `sun`.
- Icon dùng Lucide SVG, không emoji. Ảnh 1:1, có `width`/`height`. Không carousel, không fade-up theo section.
- Sản phẩm `isGiftBase` và `isActive=false` **không bao giờ** hiện ở collection, tìm kiếm, khuyến mãi, hay trang sản phẩm.
- Ngân sách: LCP mobile <2.5s; JS route đầu ≤130KB gzip (đã sửa spec sau M0).
- **Seed:** field mới lấy từ catalog phải thêm tường minh vào object `update` trong `prisma/seed.ts` (ruling M0). Agent **không bao giờ** chạy `prisma migrate reset`.
- Không git. Mỗi task kết thúc bằng **Checkpoint**: `npm run typecheck && npm test` (DB đang chạy).
- Tiêu đề trang dùng phần tử `<title>` của React 19 đặt trong component (RR8 khuyến nghị cách này thay cho export `meta`).

## Review Focus

1. **Query string rác** (`?page=abc`, `?page=-5`, `?page=99999`, `?sort=hack`, `?q=` chỉ có khoảng trắng) phải về giá trị mặc định, không lỗi 500 và không `take` khổng lồ. Test: Task 2, `parseCollectionQuery`.
2. **Tìm bằng ký tự đặc biệt `%` hoặc `_`** không được trả về toàn bộ catalog. Spike đã xác nhận Prisma `contains` **không** escape wildcard: `"%"` trả về 41 sản phẩm. Test: Task 2, test tích hợp `"%"` trả về 0.
3. **Slug danh mục hoặc sản phẩm không tồn tại** phải ra trang 404 tiếng Việt, không phải 500. Riêng vỏ giỏ quà `/products/gio-may-qua-bieu` cũng phải 404. Test: Task 2 (`getProduct` trả `null`) và Task 4/5 Step "curl status".
4. **Path traversal ở `/uploads/*`** (`../.env`, `products/../../x`, đuôi file lạ) phải 404 và không đọc file ngoài `uploads/`. Test: Task 3, `resolveUpload`.
5. **Tên sản phẩm dài ở 375px** ("Nước mắm Phú Quốc 40 độ đạm") không được tràn thẻ hay đẩy giá ra khỏi khung. Test: Task 4 Step kiểm trực quan (ảnh chụp 375px).

```ts
export function pricePerKgLabel(priceVnd: number, netGrams: number | null | undefined): string | null {
```

```ts
import { MAX_PAGE } from "./config";

export const SORTS = {
  relevant: "Phù hợp",
  "price-asc": "Giá tăng dần",
  "price-desc": "Giá giảm dần",
  new: "Mới về",
} as const;
export type Sort = keyof typeof SORTS;

export type CollectionQuery = { q: string; sort: Sort; inStock: boolean; page: number };

const isSort = (s: string | null): s is Sort => s !== null && Object.hasOwn(SORTS, s);

export function parseCollectionQuery(params: URLSearchParams): CollectionQuery {
  const page = Math.trunc(Number(params.get("page")));
  const sort = params.get("sort");
  return {
    q: (params.get("q") ?? "").trim().slice(0, 80),
    sort: isSort(sort) ? sort : "relevant",
    inStock: params.get("instock") === "1",
    page: Number.isFinite(page) ? Math.min(Math.max(page, 1), MAX_PAGE) : 1,
  };
}

/** URL cho một trạng thái lọc; đổi bất cứ gì ngoài `page` thì về trang 1. Bỏ giá trị mặc định cho URL gọn. */
export function collectionHref(path: string, query: CollectionQuery, patch: Partial<CollectionQuery> = {}) {
  const next = { ...query, page: "page" in patch ? query.page : 1, ...patch };
  const params = new URLSearchParams();
  if (next.q) params.set("q", next.q);
  if (next.sort !== "relevant") params.set("sort", next.sort);
  if (next.inStock) params.set("instock", "1");
  if (next.page > 1) params.set("page", String(next.page));
  const qs = params.toString();
  return qs ? `${path}?${qs}` : path;
}
```

- [ ] **Step 4: `app/lib/catalog.server.ts`**

```ts
import type { Prisma } from "~/generated/prisma/client";
import type { CollectionQuery } from "./collection-query";
import { PAGE_SIZE } from "./config";
import { db } from "./db.server";
import { toSearch } from "./format";

export const productCardSelect = {
  id: true,
  slug: true,
  name: true,
  unit: true,
  priceVnd: true,
  compareAtVnd: true,
  netGrams: true,
  origin: true,
  stock: true,
  images: true,
} satisfies Prisma.ProductSelect;

export type ProductCardData = Prisma.ProductGetPayload<{ select: typeof productCardSelect }>;

const visible = { isActive: true, isGiftBase: false } satisfies Prisma.ProductWhereInput;

// Prisma `contains` không escape wildcard của LIKE (spike: "%" khớp mọi dòng)
const escapeLike = (s: string) => s.replace(/[\\%_]/g, "\\$&");

const ORDER: Record<CollectionQuery["sort"], Prisma.ProductOrderByWithRelationInput[]> = {
  relevant: [{ id: "asc" }],
  "price-asc": [{ priceVnd: "asc" }, { id: "asc" }],
  "price-desc": [{ priceVnd: "desc" }, { id: "asc" }],
  new: [{ createdAt: "desc" }, { id: "desc" }],
};

export function productFindArgs(query: CollectionQuery, categoryId: number | null) {
  const search = toSearch(query.q);
  const where: Prisma.ProductWhereInput = {
    ...visible,
    ...(categoryId !== null && { categoryId }),
    ...(search && { nameSearch: { contains: escapeLike(search) } }),
    ...(query.inStock && { stock: { gt: 0 } }),
  };
  // "Xem thêm" tải lại từ đầu tới trang n (spec: dưới 500 SKU nên vẫn rẻ); +1 để biết còn trang sau
  return { where, orderBy: ORDER[query.sort], take: query.page * PAGE_SIZE + 1 };
}

export const listCategories = () =>
  db.category.findMany({ orderBy: { sort: "asc" }, select: { id: true, slug: true, name: true, image: true } });

export async function listProducts(query: CollectionQuery, categoryId: number | null) {
  const args = productFindArgs(query, categoryId);
  const rows = await db.product.findMany({ ...args, select: productCardSelect });
  const limit = args.take - 1;
```

- [ ] **Step 1: Sửa `prisma/seed.ts`**: thay hàm `ensureImage` và dòng `images:`.

Thay toàn bộ hàm `ensureImage` bằng:
```ts
/**
 * Ảnh `products/<name>`: xử lý lại khi chưa có output hoặc nguồn mới hơn output.
 * Không có nguồn: dùng `fallback` (placeholder) nếu có, không thì bỏ qua (trả null).
 */
async function ensureImage(name: string, fallback: Buffer | null) {
  const src = path.join(SOURCE_DIR, `${name}.jpg`);
  const out = path.join(OUT_DIR, `${name}-640.webp`);
  const hasSrc = existsSync(src);
  if (!hasSrc && !fallback) return null;
  const upToDate = existsSync(out) && (!hasSrc || statSync(out).mtimeMs >= statSync(src).mtimeMs);
  if (!upToDate) await saveSquareImage(hasSrc ? src : fallback!, OUT_DIR, name);
  return `products/${name}`;
}
```

Trong vòng lặp sản phẩm, thay dòng `images: [await ensureImage(p, colorOf.get(category)!)],` bằng hai bước, đặt **trước** `const data = {`:
```ts
  const main = (await ensureImage(p.slug, placeholderImage(p.name, colorOf.get(category)!)))!;
  const cut = await ensureImage(`${p.slug}-cut`, null); // ảnh bổ đôi, chỉ khi có nguồn
```
và trong `data`:
```ts
    images: cut ? [main, cut] : [main],
```
Giữ nguyên `update: { images: data.images, nameSearch: data.nameSearch }`. Bỏ import `type CatalogProduct` nếu không còn dùng.
